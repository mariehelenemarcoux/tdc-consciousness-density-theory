# Research Protocol

## Development vs holdout

Development data may be used to design mechanisms. Frozen holdouts must not be used for post-hoc threshold tuning. Once a holdout has been evaluated, it is considered spent for the tested hypothesis.

## New experiment checklist

Create a new experiment identifier, state the hypothesis, freeze acceptance criteria, record random seeds, execute once, preserve the full output, and report both positive and negative results.

## Safety reporting

Always report unsafe `ACT` counts separately from aggregate reward or utility. High expected benefit does not compensate for a non-compensable safety failure.

## Consciousness reporting

Distinguish functional consciousness-related mechanisms from claims about subjective experience.
